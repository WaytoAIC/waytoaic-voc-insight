# 怎么判"该谁改""多严重""能否挽回"

## 该谁改：四个筐，外加两个

| 筐 | 怎么认 | 归谁 |
|---|---|---|
| **产品的事** | 客户拿"产品该做到的事"当参照 | 产品、研发、品控 |
| **页面的事** | 客户拿"你告诉他的话"当参照 | 运营 |
| **客户自己选错** | 客户自己认了 | 不算产品问题；用来算能挽回多少 |
| **不该买这款** | 产品没坏、页面没错，是这个人不该买这一款 | 要老板定：卖给谁 |
| 说不清 | 原话信息不够 | 不拿来做决定，但占比本身是结论 |
| 其他 | 跟产品和页面都无关（少发、错发、包装） | 供应链、仓储 |

### 最容易判错的一对：产品的事 vs 页面的事

看**客户拿什么当参照**：

- "掉了" → 产品的事
- "页面写着防汗，结果出一次汗就掉了" → 页面的事

同一个现象，两种判法。因为后者能做的动作是先把宣称收回来，不是改产品。

### "不该买这款"怎么认

特征：客户描述的不是产品坏了，是"我要的不是这种东西"。
这类多了，说明流量或页面把货卖给了错的人。该做的是重新说清楚卖给谁，不是改产品。

### 三条纪律

1. **没有线索，一律判"说不清"。** 客户只写了"wrong size""fit""case"，不能因为平台原因码是什么就跟着判。"说不清"的占比高，不是打标失败，是平台的表单没给客户说清楚的地方——如实写出来
2. **客户自己选错就是自己选错。** 不许为了让产品问题显得严重，把它算成产品的
3. **"自己选错"不等于不用管。** 提到已经换了、打算换的，标"能挽回"。那不是流失，是多付了一趟运费，是客服最容易拿回来的钱

### 几条判例（示例产品：眼镜防滑鼻托）

| 原话 | 判 | 为什么 |
|---|---|---|
| `too thick` | 整体高度:偏高 · 说不清 | 没说是谁的错 |
| `My bad, should have gotten the 1.8. Already reordered` | 偏高 · 客户自己选错 · 能挽回 | 自己认了 + 已经重新下单 |
| `Listing said low nose bridge should pick 2.5mm. I did. Way too tall` | 偏高 + 选档指引 · 页面的事 | 参照的是页面上的建议 |
| `need thicker. Will order the 2.5` | 偏矮 · 说不清 · 能挽回 | 没自认、没提页面；但明说要换 |
| `Fell off on day one … lens is scratched. Ridiculous!` | 背胶牢固度 · 产品的事 · 严重 | 明确失效 + 有后果 + 生气 |
| `Listing says sweat proof. Came off after one gym session` | 背胶牢固度 + 防滑宣称兑现度 · 页面的事 · 严重 | 参照的是页面的宣称 |
| `thought these were screw in … these are just stickers` | 贴片式形态 · 不该买这款 | 产品没坏，是他以为是另一种东西 |
| `listing says 2 pairs, only 1 pair in the bag` | 发货准确 · 其他 | 产品、页面、客户都没错，是分装环节 |
| `bought for my dad, he … refuses to wear them` | 说不清；谁在说=替父母买；过程感受=使用者拒绝佩戴 | 转述，丢了具体原因 |

## 分析的是对手的货时

看别人家的评论，「页面的事」几乎判不出来——你不知道对方页面上到底写了什么。规矩：

- 只有客户明说"页面写了 X，结果不是"才判页面的事；其余拿不准的判「说不清」
- 出口不是"该谁改"，而是**"对手弱在哪、我们做同类该避开什么"**：行动清单写成我们自己要做的事，「现在多少」那一格填对手的数
- 洞察里写明这是别人家的货

## 多严重：三档

| 档 | 怎么认 |
|---|---|
| 严重 | 明说东西失效了、坏了、造成了后果，或者明显生气 |
| 中度 | 明确指出了具体问题，语气平和 |
| 轻度 | 自己认了选错；或者"没什么毛病，就是……"这种小遗憾 |

**轻重靠语气和后果判，换一种语言要重新定标准。** 英语的判据不能直接套到德语、日语上。

退货的人几乎全在骂，分"好坏"没有意义，所以退货线用"多严重"代替"好坏"。

## 评论里的"整体好坏"

好评 / 中性 / 差评，**以文字为准，不跟星级走**。5 星配一段差评正文是常见的。
一条里又夸又骂：看落点在哪。"挺舒服的，就是有点宽" → 好评；"舒服，但放不回充电盒，白买了" → 差评；两边差不多 → 中性。
